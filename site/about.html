About this site

A static site: plain HTML, CSS and the extension's own JavaScript. It loads nothing from other servers, sets no cookies, and collects nothing. The libraries in the demos are copies in vendor/; the dhtmlx-gantt stylesheet is copied without its web font, which would otherwise be loaded from Google's servers.

It is generated by npm run site in the repository, which also runs the automated check below. The check looks at headings, landmarks, the skip link, visible focus, colour contrast, names of links and buttons, and network requests. It is a set of automated rules, not a review by people who use assistive technology, and it does not check the charts' own markup (that is what the audit is for).

Automated check

Run 2026-11-20 in Chromium (Playwright) by scripts/site/check.js. Automated rules only: they find missing structure and low contrast, not whether the pages are easy to use with a screen reader. The charts' own markup is left out here; the audit checks it.
