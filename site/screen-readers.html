How to try with a screen reader

Open one of the demos, move into the chart, and ask it questions.

Only the VoiceOver steps have been tried, by the author. The NVDA and JAWS steps follow how these screen readers usually handle web applications; they have not been tested with this extension yet. If something does not work as described, that is useful to know.

Everywhere

  1. Open the dhtmlx-gantt demo. Make sure the switch says the extension is on.
  2. Move to the chart with Tab, not with a mouse click. Focus lands on the first task row.
  3. Move between tasks with the up and down arrow keys. Each row says the task's name, dates, duration and progress.
  4. Press Shift+H for the list of keys, and again within five seconds for the next group.
  5. Good first questions: on "Launch", Shift+D (what it depends on); on "Testing", Shift+O (what runs at the same time); anywhere, Shift+V (overview).

VoiceOver on a Mac

  1. Use Safari. Turn VoiceOver on with Command+F5.
  2. If arrow keys move the VoiceOver cursor instead of the chart's focus, turn Quick Nav off with Left Arrow+Right Arrow pressed together.
  3. In Safari, Tab may skip buttons; Option+Tab reaches every control.
  4. Results of jumps and of the task form are heard first, as part of the row; answers to questions and results of keyboard edits come after the row is read.

NVDA on Windows (not yet tested)

  1. Use Firefox or Chrome. Move to the chart with Tab; NVDA should switch to focus mode on its own. If letters are read as browse-mode quick keys instead, press NVDA+Space to switch to focus mode.
  2. The reading keys (Shift with a letter) only reach the chart in focus mode.

JAWS on Windows (not yet tested)

  1. Use Chrome or Edge. Move to the chart with Tab; JAWS should turn on forms mode. If it does not, press Enter on the row, or turn the virtual cursor off with Insert+Z.

Step by step

The repository has a full list of checks with the exact expected texts (TESTING.md), and a helper page that walks through them one by one and collects your answers into a report (demo/manual-test.html; run npm run demo in the repository first).
